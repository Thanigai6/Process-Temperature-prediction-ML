Project M10 – Process Temperature Prediction Using Air Temperature

📌 Project Overview

This project uses Machine Learning to predict the process temperature of a milling machine based on the surrounding air temperature.

The main idea is to understand how changes in air temperature affect the temperature inside an industrial machine. A Linear Regression model is used to identify the relationship and make predictions.

🎯 Objectives

- Predict machine process temperature using air temperature.
- Understand the relationship between air temperature and machine temperature.
- Apply Machine Learning in industrial applications.
- Support better thermal management and maintenance planning.

🛠️ Technologies Used

- Python
- Pandas
- Matplotlib
- Scikit-learn
- VS Code

📊 Dataset

Dataset: AI4I / Machine Predictive Maintenance Dataset
Source: Kaggle
Input: Air Temperature (K)
Output: Process Temperature (K)

⚙️ Working Process

1. Download and load the machine maintenance dataset.
2. Clean and prepare the required data.
3. Select air temperature as the input.
4. Select process temperature as the output.
5. Train the Linear Regression model.
6. Test the model and calculate its accuracy.
7. Predict process temperature for new air temperature values.
8. Visualize the results using a graph.

📈 Model Performance

- Algorithm: Linear Regression
- R² Score: 0.756
- Average Error: 0.59 K
- Prediction Example: When air temperature is 300 K, the predicted process temperature is approximately 310 K.
